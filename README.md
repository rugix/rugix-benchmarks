# Rugix Benchmarks

Code, inputs, and results for reproducing Rugix benchmarks. Each experiment lives in its own directory with a README and its required tools.

| Benchmark | Measurements |
| --- | --- |
| [Delta-Update Byte Simulations](benchmarks/delta-updates/README.md) | Download-size estimates across two years of Debian images. |
| [Native Adaptive-Update Installations](benchmarks/adaptive-downloads/README.md) | Rugix and RAUC installation times and actual network traffic at different latencies. |

Follow the README in the selected benchmark directory to reproduce its results.

Benchmark code is available under either the [Apache-2.0](LICENSE-APACHE) or [MIT](LICENSE-MIT) license. External tools retain their own licenses.
